# Learn Dutch with Andy 🇳🇱

Japanese-language Dutch A1–A2 revision game for adults, created by **Andy Chum**.

**Play the game:** https://learn-dutch-with-andy-revision.awakeazure4.chatgpt.site

## Features

- **300 practice items:** 75 vocabulary, 75 grammar, 75 sentence-builder variations (25 sentence patterns × 3), 75 reading questions (15 passages × 5).
- Easy (A1) and Medium (A2) levels with topic selection.
- Japanese explanations and instant answer feedback.
- Browser-based Dutch text-to-speech (normal/slow).
- Mistake review and progress saved locally in the learner's browser.
- Mobile-friendly, no account required.

## Run locally

Open `index.html` in a browser, or serve the directory using a simple static server. All application assets are self-contained in these three files: `index.html`, `data.js`, `app.js` (Google Fonts are optional).

## Content and attribution

Original practice questions are informed by Andy's own Dutch Approach A1 revision notes, private lesson revision materials and CNaVT A2 study topics. This is an independent learning resource and **not officially affiliated with or endorsed by CNaVT or Dutch Approach**. The question bank does not reproduce exam passages.

Browser pronunciation quality depends on the device's installed Dutch voice.
